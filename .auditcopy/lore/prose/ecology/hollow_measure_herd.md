# The Hollow Measure Herd

The plains' one large migratory herd, which returns on a cycle nobody on the ground has ever been able to predict and which therefore functions as the tier's only moving calendar.

It exists because temporal law is written here at 0.5-2.0 with qi_law at the floor, so the one cycle the plains actually keep is the flood - and a herd that returns on the flood is a herd whose return can be waited for and planned around but not scheduled.

That makes it the tier's famine vector and its calendar at once: a bad return starves the Bitter Scrub's grazers before anything else, and a good return puts so much stock on the scrub that the next grazing season is decided in advance by animals nobody consulted.
