# The Tier Stair

The one graded route out of the Mortal Plains, and the only departure the Peak Ascent ever used.

It exists because distance is not conserved on the plains, so an unmapped road is the only kind of travel that can be repeated: the stair measures itself, and a party that has climbed it once can be shown to have done so.

It matters because it is the setting's first portable institution - a thing that can be pointed at, walked, taxed and guarded - and because everything above the plains arrived through it, which makes it the only piece of the mortal tier with a constituency on four tiers.

The stair solves the Hollow Measure by refusing it. It does not claim to be a short road or a certain road; it is a graded one, marked at intervals, and it is the one feature of the mortal plains whose position can be described the same way twice.

That makes it the setting's first road and its first border at the same time. A road that can be walked reliably can be closed reliably, so the stair is the only place on the plains where anyone can meaningfully say *this far and no further* - and it is also the only door the three higher tiers have ever used.
