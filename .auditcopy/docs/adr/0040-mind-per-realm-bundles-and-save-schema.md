# 0040 Mind per-realm bundles and save schema v3

- Status: Accepted
- Date: 2026-10-02

## Context

ADR 0009 established four tier bundles for breakthrough items. Mind Cultivation (ADR 0013/0016) needs per-realm bundles: each realm has three consumable roles (breakthrough pill, sea catalyst, meridian catalyst) that are crafted from gathered herbs and boss cores. The save schema needs a v3 migration to serialize the sea of consciousness.

## Decision

### Per-realm bundles

- Each realm has three consumable items:
  1. `mind_<realm_id>_breakthrough_pill` — entry consumable, required only when a valid attempt starts.
  2. `mind_<realm_id>_sea_catalyst` — starts the matching realm's Thức Hải strengthening milestone.
  3. `mind_<realm_id>_meridian_catalyst` — starts the matching realm's channel/resonance strengthening milestone.
- All three outputs are craft-only at alchemy.
- Each realm shares two material definitions: one gathered herb and one guardian core from its boss.
- Domains group three adjacent realm rows, yielding ten domain families.

### Availability invariant

- All mandatory preparations for entry R are obtainable and usable while the Mind actor is in R-1.
- The R1 novice route works without a started Mind path.
- A source can be difficult, but it cannot require entry to the realm it is meant to unlock.

### Save schema v3

- Added `sea` field to `Actor.to_dict()`/`from_dict()`.
- The sea serializes: `tier`, `clarity`, `turbulence`, `purity`, `structural_capacity`, `trained_stage`.
- The `mind_power` pool is serialized separately in `resources`.
- Migration: v2 saves without a `sea` field get a default sea on load.

### Grade and subtype

- Breakthrough pills: grade follows tier (mortal/spirit/immortal/divine), subtype `pill`.
- Sea catalysts: grade follows tier, subtype `tonic`.
- Meridian catalysts: grade follows tier, subtype `elixir`.
- Herbs: grade follows tier, subtype `herb`, source `gather`.
- Cores: grade follows tier, subtype `beast_core`, source `boss:<boss_id>`.

## Consequences

- 90 consumable seeds (3 per realm) are generated by `tools cultivation seed-systems`.
- The data audit validates all item/recipe/boss/domain links.
- Save schema v3 is backward compatible: v2 saves load with a default sea.
- The `mind_power` pool and sea are serialized separately but represent one reservoir.
