# Thornline

An obligate host parasite that only exists as half of somebody else.

**Why it exists.** As a free-living spore it was never going to make a living: it feeds
on refined qi, which no uncolonised body has much of. As a coloniser it feeds
continuously, survives almost anything its host survives, and does not make the host
lose weight. The colony takes a small fraction and the host is not harmed by the loss,
which is the strongest single piece of evidence that this is not a disease. It is
better than a disease, and that is the difficulty.

**Two stages, and only one of them exists.** The adult form exists only inside a host;
the free form exists only as a spore for as long as it takes to land on skin. There is
no third state. Every account of a thornline "on its own" is an account of a spore.

**The ceiling, and why it stops exactly where it does.** The colony wraps the host's
twelve ordinary meridians and goes no further, stalling at the eighth gate. It is not
a shortage — the host supplies qi in abundance. It is a **routing** problem: the
tendril layer has no passage through the host's liver, which is the first organ large
and dense enough to resist it. It has been found on the far side of that organ, and it
stops there.

**The inherited liability.** This is the only case in the record where a body's
structural limit is **inherited rather than authored**. The colony answers
introspection for the host, so the host loses the mind path as well — and the host
did nothing wrong and had no body plan that said this would happen. Any legal code
that treats a colonised person as one person and not two is making this distinction
on purpose.

**Dependence.** Total. Killing the host kills the colony within the hour, which is why
thornline-host pairs are treated as one legal person in every jurisdiction that has
ruled on it, and why `thornhost` — the rare configuration in which both halves reach
old age — is a documented event rather than a category.

**Its habitat is a species.** There is no thornline homeland because there is no
thornline environment. The host population *is* the range, which makes the commonborn
population simultaneously the species' habitat and the reason it is hunted.
