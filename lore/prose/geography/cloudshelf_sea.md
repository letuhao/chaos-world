# Cloudshelf Sea

The spirit tier's inland sea: a coastline that holds its shape because spatial law is written here, and a tide that keeps time because temporal law is.

It exists as the setting's first hard edge. Everywhere below this tier a border is a claim that can be argued; here it is water that drowns you, so the quarrel over the shelf finally has a physical form that no argument dissolves.

What makes it worth holding is that it can be crossed and farmed at once - which means the first real coastline in the setting is also the first place where two shores can both depend on it and still need to argue about it.

A coast is the setting's first honest boundary and it is worth noticing why. It is not honest because it is a straight line; it is honest because it is the same line for everybody, which is a property the mortal plains cannot manage at all and the spirit tier gets for free from a single written law.

The sea is also the first place the spirit tier can support an argument about water rather than about rock. Spirit stone and jade are held by whoever digs; the shelf is held by whoever keeps two shores from each other. Those are different skills, and a polity that has only ever been organised around mining discovers the difference late.
