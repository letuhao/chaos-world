# Widow Run

The Mortal Plains' single watercourse: dry for most of each year, full for a few weeks, and moving its bed far enough between floods to relocate every settlement built along it.

It exists because temporal law is written here at 0.5-2.0 and qi_law at the floor of its range, so the only clock the plains own is the flood - a real cycle, a thin one, and the only measurement a settlement on this ground can keep.

What makes it worth holding is that it cannot be: every downstream settlement is revocable at the next flood, so nobody invests in one twice and every settlement is a compromise between being near the water and being above it.

A river is normally a boundary that two banks agree on. This one is a boundary that moves, which means the argument about which bank is whose has to be restarted every year, and the party with the shorter memory usually wins because the water does not remember either.

It also makes the plains' only irrigation a political instrument. Whoever sits above the narrows can refuse to flood the flats, and no rule on these plains can be cited against them, because there is no unit of flow that could be measured twice to the same figure.
