# Asian Hell Pack: Minh Giới (Netherworld / Yin-Jian)

Comprehensive 500+ world map asset collection for the Asian Netherworld / Diyu / Minh Giới, designed for Chaos World's Action RPG combat, adventure exploration, puzzle mechanics, and world simulator / domain management.

* **Total Assets**: 543
* **Standard Tile Unit**: 128x128 px
* **Sub-cell Collision Unit**: 32x32 px (4x4 subcells per tile)
* **Art Direction**: Top-down orthographic ($\sim 45^\circ$), hand-painted gouache, fine ink contours (`#263A35`), upper-left directional lighting ($315^\circ$), rich East Asian / Sino-Vietnamese underworld palette.
