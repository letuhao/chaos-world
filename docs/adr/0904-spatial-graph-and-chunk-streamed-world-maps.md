# 0904 Spatial graph and chunk-streamed world maps

- Status: Accepted
- Date: 2026-10-07

## Context

Worlds, domains, rooms and map art exist but no spatial system connects them:
`DomainMap` is rooms-without-space, `WorldApi.locations` is a node list
without geography, `WorldEntry` scenes are hand-placed markers, and the
chunk pipeline lives outside the engine in `build/mapdata`. There is no
notion of a chunk, a portal, or an unload inside `res://src`.

## Decision

`SpatialNode + SpatialRelation + MapRepresentation + TravelConnection`,
in a new `worldmap` module:

- A node is `{id, kind, parent}` where `kind` is an open `StringName`
  vocabulary (town, domain, cave, pocket world — never an enum), so future
  concepts need no core change. Containment (`parent`) and travel (edges)
  are separate lists: a cave contains a secret realm while a portal edge
  joins two nodes that share no parent.
- A map representation is authored (scene path), procedural (generator
  config + seed), or hybrid (authored core + procedural surround). One
  runtime scene system serves all three.
- Cells belong to chunks; chunks have per-map sizes (no global 16); regions
  merge chunks for streaming. Coordinates are per-node local (cell,
  chunk-local, map, pixels) — unrelated worlds never share a plane.
- Generation is `seed -> context -> passes -> chunk`, each pass declaring
  `requires()`. Deterministic hash RNG: untouched chunks regenerate, only
  mutations persist (per-chunk overlay, `to_dict`/`from_dict`).
- Streaming separates data, scene and render ranges; only instantiated
  ranges cost nodes. The domain room system is NOT replaced: a domain node
  points at its existing `DomainMap` template, which becomes one more map
  representation among others.

## Consequences

- `worldmap` depends on `contracts` + `core` only; `ui/` and `app/` reach it
  through `WorldmapApi`. Asset choice reads `map-asset-index.jsonl` at
  runtime by metadata (environment/category/archetype/footprint), never by
  hard-coded path.
- Measured while building: passes never see chunk coordinates, so every
  chunk generated byte-identically — the generator mixes `(cx, cy)` into the
  stream seed. Any test BFS over generating data carries a visit cap, for
  the same reason: the world past the cache is infinite.
- What this ADR does NOT do: replace `DomainScene`/`WorldEntry`, wire save
  envelopes (mutations persist in-session; envelope keys are a follow-up),
  or promise multiplayer replication of streamed state.
